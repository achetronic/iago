## What changed

- The daemon starts on demand when the window opens. Running `iago daemon run`
  first is no longer needed.
- The README explains how to install the desktop entry and the icon, so Iago
  appears in the app menu and launches with a click.

## Download

Pick your platform and unpack it:

```sh
tar xzf iago-0.1.1-linux-amd64.tar.gz
cd iago-0.1.1-linux-amd64
./iago
```

SHA-256 sums are in `checksums.txt`.
